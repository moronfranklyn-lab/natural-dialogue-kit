# 长期记忆：后续设计边界

本期没有实现记忆服务。本页用于后续产品设计，不能作为当前工具包的能力声明。

| 输入 | 应保留的区分 | 风险 |
|---|---|---|
| 我朋友喜欢威士忌 | 第三方主语 | 误记成本人偏好 |
| 今天累死了 | 临时状态、时间 | 升格为永久特质 |
| 我把你尾巴踩了 | 角色玩笑 | 冒充真实共同经历 |
| 以后别叫我这个称呼 | 用户交流偏好与作用域 | 被旧历史覆盖 |
| 我以前喜欢甜的，现在不喜欢了 | 时间、否定与更正 | 继续召回旧偏好 |
| 把那件事忘掉 | 删除对象与关联来源 | 从摘要或历史重新写回 |

人格配置表达助手的默认身份；用户偏好表达某位用户对相处方式的选择；事实记忆需要来源与时间。它们可以在具体系统中共用表，也可以分表，概念区分不强制存储架构。

模型自行标注“用户明确要求记忆”不是授权证据。需要回到用户原话与应用规则核实；普通分享不自动等于长期保存同意。

业务库存、收藏、账户状态等仍以业务系统为准，不由自由文本记忆覆盖。用户纠正/删除后，召回和提取链路都要处理，避免旧摘要复活。

后续评测应分别测误记、漏记、相关召回、纠正/删除、延迟与成本。是否需要向量索引或图结构取决于实际失败，不先选基础设施。

曾讨论外部记忆项目，但具体仓库、许可与实现尚未核实，本仓库不依赖或背书该项目。
