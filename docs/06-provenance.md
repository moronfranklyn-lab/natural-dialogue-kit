# 来源、改编与证据范围

## 本仓库内容

维护者 Ethan 将陪伴型调酒 Agent 的人格迭代经验抽象为独立工具包。文档、场景、脚本与 Skill 为本次整理；吧台猫配置参考维护者项目中的人格版本，经过改写与去业务耦合。

`bar-cat-v1.2-adapted.json` 的名称表示源自一次 v1.2 迭代方向，不表示与原生产 bundle 相同，也不继承其生产提示哈希。`neutral-template.json` 是新编中性模板，未经过本仓库真实模型评测。

## 第三方参考

设计讨论中参考过用户提供的网友 QQ 群人格卡、聊天截图，以及 DeepSeek Harness 中模型提出的意见。原帖作者、原始发布地址与许可未完整核实，因此不收录原卡全文、截图、原角色专属设定或未经核实的来源链接。

“避免表达配额、辨别语境、人格与执行分离”等在本仓库以自身实现经验重新表述，不主张这些一般思想由本项目首创。DeepSeek Harness 是讨论工具，不代表其维护方认可本项目，也不构成效果证据。

## 证据级别

历史运行计数来自原项目内部记录，已在案例文档注明验证范围与复现限制；本仓库没有附原始私有日志，也不将这些数字作为公开基准成绩。

仓库附带的 demo 全部人工构造。真实模型输出摘录只在案例页明确标注，不能与 demo 混淆。使用者实测与多用户反馈仍待补充。
